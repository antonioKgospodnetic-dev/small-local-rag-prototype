# small-local-rag-prototype
Mali prototip lokalnog rag sustava koji koristi ChromaDB i LM Studio.

## Opis sustava
Za konstruiranje RAG-a se koristi RAG_constructor.py
Za stvaranje konteksta se koristi Context_provider.py
Za slanje upita datoteci spremljenoj u vektorskoj bazi prema LLM-u, koristi se Prompt_sender.py

## Tehnologije
- ChromaDB
- LM studio
- python libraries
